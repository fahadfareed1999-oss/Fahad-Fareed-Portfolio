# Fahad Fareed — Digital Media & Growth Portfolio

A responsive, single-page portfolio website built with HTML and CSS.

## Before publishing
1. Open `index.html` in a text editor.
2. Find `YOUR_EMAIL@example.com` and replace it with your preferred business email.
3. Review all metrics and case-study claims so they accurately reflect your work and that you have permission to share them.

## Publish with GitHub Pages
1. Sign in at https://github.com.
2. Click **New repository**.
3. Name it `fahad-fareed-portfolio`.
4. Set it to **Public** (required for the simplest free GitHub Pages setup) and create the repository.
5. Choose **Add file → Upload files**.
6. Upload `index.html` and this `README.md` from this folder. Commit the changes.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch `main` and folder `/ (root)`, then click **Save**.
10. Wait for the Pages deployment to finish. Your site URL will normally be `https://YOUR-GITHUB-USERNAME.github.io/fahad-fareed-portfolio/`.

If you want a URL like `https://YOUR-GITHUB-USERNAME.github.io/`, name the repository exactly `YOUR-GITHUB-USERNAME.github.io` instead.

## Notes
- This is a static website; it does not need a server or build step.
- The contact link opens the visitor's email app. It is not a form submission backend.
- Google Fonts requires an internet connection; fallback fonts are included.
